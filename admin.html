★ ADMIN PANEL ★

Private. Sign in with the admin account you created in Firebase.
First-time setup (5 minutes)
  1. Firebase console → Build → Authentication → Get started → enable Email/Password.
  2. On the Users tab click Add user: make your admin email + a long password. Copy the User UID.
  3. Realtime Database → Rules: paste the contents of firebase-rules.json, replace every PASTE_YOUR_ADMIN_UID_HERE with that UID, and Publish.
  4. Project settings → General → Web API key: paste it above. It's stored only in this browser.
